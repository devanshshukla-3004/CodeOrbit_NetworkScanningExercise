# CodeOrbit Network Scanning Exercise

Cyber Security Internship project for CodeOrbit Tech.

Authorized localhost Nmap exercise using:
`nmap -sV -sC -p- --min-rate=1000 -T4 localhost`

Evidence includes raw scan output, HTTP headers, the report, screenshots, and walkthrough video.

Target scope: localhost / 127.0.0.1 only.
